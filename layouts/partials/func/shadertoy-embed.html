{{- /* Renders one Shadertoy shader. Default is a poster, not an iframe. Shadertoy sits behind Cloudflare, and a cross-origin iframe reaches it without Shadertoy's cookies — Chrome blocks third-party cookies by default — so Cloudflare serves a bot challenge instead of the shader, and that challenge page's X-Frame-Options refuses framing. The visitor gets "refused to connect" in a grey box. Opening the same embed URL in a tab works fine, which is what makes the poster a real substitute: it is a picture of the shader that opens the working page in one click. Set `shaderEmbed: true` in a page's front matter to try the iframe anyway. Expects a dict: id (required), title, cover, embed, gui, paused. */ -}} {{- $id := .id -}} {{- $title := .title | default (printf "Shadertoy shader %s" $id) -}} {{- $url := printf "https://www.shadertoy.com/view/%s" $id -}} {{- $cover := .cover -}}
